# AFFiNE MCP Sandbox Template

Профиль песочницы для интеграции **Antigravity** с **AFFiNE Cloud** (`https://app.affine.pro`) или внешними **Self-Hosted** серверами через протокол **Model Context Protocol (MCP)**.

---

## Возможности

- **Полный спектр MCP-инструментов (108 canonical tools):**
  - Чтение и создание документов (docs / pages), древовидная структура блоков.
  - Управление базами данных (database): строки, колонки, свойства, фильтры.
  - Поиск по содержимому воркспейса (full-text search).
  - Работа с журналом (AFFiNE Journal) и метаданными документов.
  - Экспорт и импорт Markdown.
- **Yjs CRDT & Realtime WebSocket:**
  - Поддержка бесконфликтного слияния при параллельном редактировании человеком в браузере и агентом в песочнице.
- **Сетевая изоляция без изменений сетевых настроек:**
  - Шаблон использует внешние серверы (WAN). Правила Netfilter/iptables песочницы защищают локальную сеть хоста (LAN RFC 1918), при этом пропуская защищенный HTTPS/WSS-трафик к серверам AFFiNE.
- **Изолированная персистентность сессий (Principle of Least Privilege):**
  - Авторизационные токены, куки и конфигурация MCP сохраняются строго в изолированном томе текущего проекта `agy-gemini-data-${localWorkspaceFolderBasename}` (`~/.gemini/affine-mcp`).
  - Данные AFFiNE и MCP-инструменты **не утекают** в другие проекты или другие песочницы: сторонний агент в другом workspace не видит инструментов AFFiNE и не имеет доступа к вашей сессии. При этом внутри данного проекта сессия полностью сохраняется при перезапусках контейнера.

## Что требуется для подключения к AFFiNE Cloud

Для подключения к официальному сервису **AFFiNE Cloud** (`https://app.affine.pro`) требуется:

1. **Сессионный Cookie браузера (`Cookie` header):**
   - *Почему куки, а не пароль?* Сервер `app.affine.pro` защищен Cloudflare Turnstile, который предотвращает автоматический вход по email/паролю сторонними скриптами.
   - *Как получить:*
     1. Откройте в браузере [https://app.affine.pro](https://app.affine.pro) и войдите в свой аккаунт.
     2. Нажмите `F12` (Developer Tools) и перейдите на вкладку **Network** (Сеть).
     3. Кликните на любой документ в интерфейсе или обновите страницу.
     4. Выберите в списке сетевых запросов любой запрос к `app.affine.pro` (например, `/graphql`).
     5. В панели **Request Headers** найдите заголовок `Cookie` и скопируйте всю его строку целиком (содержит параметр `affine_session=...`).
2. **Workspace ID (опционально, определяется автоматически):**
   - В адресной строке браузера: `https://app.affine.pro/workspace/<WORKSPACE_ID>/...`.
   - Если не указывать вручную, утилита настройки сама запросит список ваших воркспейсов через GraphQL API и предложит интерактивный выбор.

## Быстрый старт

### 1. Инициализация проекта с шаблоном

```bash
# Из корневой директории antigravity-sandbox:
./scripts/init-sandbox.sh --template affine-mcp --target ~/my-affine-project
```

Затем откройте созданный проект в VS Code:
```bash
code ~/my-affine-project
```
VS Code предложит: *"Reopen in Container"* (Открыть в контейнере).

### 2. Подключение к AFFiNE (Мастер настройки)

В терминале запущенного контейнера выполните:

```bash
affine-setup
```

Мастер предложит:
1. Выбрать **Connect to AFFiNE Cloud**.
2. Вставить скопированный Cookie (ввод скрыт для безопасности).
3. Автоматически обнаружить доступные воркспейсы и выбрать рабочий воркспейс по умолчанию.
4. Запустит автоматическую проверку `affine-mcp doctor` для подтверждения соединения.

## Управление через CLI

Внутри контейнера доступны команды утилиты `affine-mcp`:

| Команда | Описание |
| :--- | :--- |
| `affine-setup` | Запуск интерактивного мастера онбординга и диагностики |
| `affine-mcp status` | Проверка текущего статуса аутентификации и активного воркспейса |
| `affine-mcp doctor` | Полная диагностика: доступность GraphQL, валидация сессии, WebSocket |
| `affine-mcp workspaces` | Вывод списка доступных рабочих пространств аккаунта |
| `affine-mcp workspace <id>` | Переключение рабочего пространства по умолчанию |
| `affine-mcp show-config` | Отображение текущей конфигурации (секреты скрыты) |

## Конфигурация Antigravity MCP

В файле `~/.gemini/config/mcp_config.json` автоматически прописывается сервер:

```json
{
  "mcpServers": {
    "affine": {
      "command": "affine-mcp"
    }
  }
}
```

Агент Antigravity автоматически обнаруживает зарегистрированные инструменты `affine_*` при запуске сессии.

### Альтернатива: переменные окружения

Если вы предпочитаете передавать параметры явно (например, в CI/CD или через `.env`), укажите их в секции `env`:

```json
{
  "mcpServers": {
    "affine": {
      "command": "affine-mcp",
      "env": {
        "AFFINE_BASE_URL": "https://app.affine.pro",
        "AFFINE_COOKIE": "ваша_сессионная_кука",
        "AFFINE_WORKSPACE_ID": "идентификатор_воркспейса"
      }
    }
  }
}
```

## Диагностика и решение проблем

- **Ошибка `UNAUTHENTICATED` / `401 Unauthorized`:**
  - Сессионная кука AFFiNE Cloud истекла. Обновите страницу `app.affine.pro` в браузере, скопируйте свежий Cookie и повторно выполните `affine-setup`.
- **Сеть и DNS (`ENOTFOUND`):**
  - Проверьте доступность DNS Quad9: `nslookup app.affine.pro`. Внешний трафик в WAN открыт по умолчанию.
- **Смена воркспейса:**
  - Выполните `affine-mcp workspaces`, найдите нужный `id` и выполните `affine-mcp workspace <id>`.
